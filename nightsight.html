Origine & inspiration

NightSight n'est pas parti d'une page blanche : le projet a démarré comme une reconstruction fidèle d'un modèle open-source, avant de devenir un terrain d'expérimentation thermique.

Point de départ : le pack de plans PVS-69 Alpha 1/2 de Vonscherfarm. Reconstruire ces jumelles de vision nocturne pièce par pièce a surtout été l'occasion de prendre en main mon imprimante 3D pour de vrai, sur un modèle exigeant en tolérances.

Modèle de référence — PVS-69 Alpha 1/2, Vonscherfarm
Backplate modifiée — première pièce personnalisée

Une fois le modèle de base reconstruit, j'ai commencé à modifier certaines pièces — notamment la backplate — avant de monter les jumelles complètes. Le tube de vision nocturne d'origine (design Vonscherfarm) est resté la base mécanique du projet.

C'est une fois les jumelles montées que l'idée est venue : rien n'empêche de remplacer les caméras infrarouges par une caméra qui capte ce que nous émettons plutôt que ce qu'on réfléchit — une caméra thermique. Elle sort elle aussi un signal analogique, exploitable de la même façon dans le tube. Elle tire plus de courant, mais ça reste largement gérable. Il a en revanche fallu retravailler la façon dont le tube était conçu pour accueillir son nouvel objectif.

Modélisation 3D

Toutes les pièces sont dessinées sur mesure dans Fusion 360. La coupe transversale révèle l'imbrication précise des modules caméra, écran et chemin optique. La version thermique est entièrement conçue depuis le début — le boîtier NV s'inspire du design open-source de Vonscherfarm.

02

Impression & itérations

Plusieurs passes d'impression sur Bambu Lab pour affiner les tolérances — PLA pour les prototypes rapides, PETG pour les pièces finales. Le défi principal : les logements du combo écran/optique doivent être précis au dixième pour que l'image soit nette à distance d'œil confortable. Chaque itération de charnière implique de réimprimer et re-câbler.

Construction & câblage

Buck converter — régulation 5V → 4V pour les caméras

Le 5V de la batterie externe est abaissé à 4V par un buck converter MP1584 avant d'alimenter les caméras. L'électronique en elle-même est simple — la vraie difficulté est de faire transiter tous ces câbles à travers les axes de rotation des charnières.

Défis techniques

01
Câblage dans les charnières
Faire passer alimentation + signal CVBS à travers l'axe de rotation sans friction ni rupture. Solution : fils 26AWG torsadés dans l'axe creux imprimé.
02
Intégration optique
Le combo écran/optique est un module tout-en-un — le défi était d'imprimer le boîtier aux bonnes dimensions pour que l'image soit nette à distance d'œil confortable. Plusieurs itérations d'impression pour trouver la bonne cote.
03
Adapter le thermique
Intégrer le module thermique dans le même format de boîtier NV — géométrie d'objectif différente, résolution différente. Tout remodéliser sans repartir de zéro.

Prochaines étapes

Fusion sensorielle
NV + thermique combinés
Le thermique ne voit pas à travers les vitres, miroirs ou surfaces réfléchissantes — là où le NV excelle. L'idée : utiliser un Raspberry Pi pour superposer les deux flux et faire ressortir uniquement les hotspots thermiques sur l'image NV. Le meilleur des deux mondes.

Amélioration optique
Remplacement des objectifs caméra
Les Runcam Night Eagle 3 V2 ont de bons capteurs mais des objectifs d'origine limités. L'idée serait de les remplacer par des objectifs à plus large ouverture numérique pour gagner en sensibilité et en champ de vision — surtout en très basse lumière.
