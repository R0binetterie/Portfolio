Architecture électronique

L'alimentation principale est une source 24V pour les drivers moteur. Deux buck converters génèrent le 10V pour la caméra thermique et le 5V pour le Raspberry Pi. Le RPi traite l'image thermique CVBS et commande les deux microstep drivers via GPIO.

Schéma électrique complet — 24V → drivers NEMA 17 · 3V3 avec résistances pull-down → GPIO fins de course RPi · CVBS caméra → DAC USB → RPi
